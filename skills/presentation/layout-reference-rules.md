# DevX Presentation — Layout Reference Rules
Status: working design guidance, not a replacement for approved DevX identity.

## Source precedence
1. Approved DevX assets and explicit design decisions
2. DevX website Figma and observed brand tokens
3. DevX specialized skills already in this repository
4. External deck references for composition and storytelling only

## Brand lock
- DevX palette, CooperL/InterD typography, approved wordmark, gradients, imagery, illustrations and visual motifs must come from DevX sources.
- Never recreate the DevX wordmark as ordinary text. If SVG is unavailable, flag it as missing.
- Never borrow external deck brands' colors, fonts, logos, motifs, photography, or visual identity.

## Composition vocabulary
Select based on content, not a fixed slide sequence:
1. Statement + relevant visual — asymmetric split
2. Full-bleed visual — minimal, high-contrast copy
3. Editorial columns — clear hierarchy, deliberate reading flow
4. Visual mosaic — varied scale and crop, one narrative
5. Structured comparison — tables, matrices, before/after
6. Typography-led pause — one important idea
7. Case-study showcase — visual evidence and concise context
8. Brand-system specimen — precise grids and usage demonstration
9. Process / architecture diagram — relationships, steps and ownership
10. Analytics showcase — sourced data with accurate labels and context

## Lessons from supplied reference decks
- Filmsupply: cinematic image mosaics, split image/text compositions and dark/light legibility.
- Studio Linear: structured comparison tables, dense content with purpose-built hierarchy, case-study layouts.
- Something Else: restrained framing and project visuals as the hero.
- Nike Empower: narrative rhythm and shifts between restrained strategy and expressive applications.
- OpenAI and AsiHome guidelines: document logo, typography, grids, spacing, contrast, chart styles and usage examples systematically.
- Sporty & Rich / Zoe Spurgeon: editorial asymmetry and thoughtful image sequencing, but do not adopt unreadably small PDF body copy for projected slides.
- Chronicle references: content-specific archetypes, visual pacing, image purpose and clean hierarchy.

## Slide selection rules
- One clear argument per slide, with evidence where needed.
- Match composition to information type; avoid repeated rounded-card grids.
- Alternate visual density, contrast and scale to create pacing.
- Real website screenshots, product/UI details, technical systems and verified evidence should take precedence over decorative imagery.
- Never fabricate outcomes, customers, quotes, partnerships or dates.
- Validate brand fidelity, slide legibility, visual relevance and editable output.

## Required QA
- Authentic DevX identity (logo, typography, palette, illustration style)
- Layout serves content
- Text readable at presentation size
- Adequate contrast
- Visuals relevant and not generic filler
- Claims sourced or clearly marked draft
- No off-slide elements, clipping or accidental collisions

External references are a grammar for composition, not a style source.
